# Project notes

- Personal project. Uses the public npm registry via project `.npmrc` (global npm config points to an unreachable corporate Nexus).
- Verify with: `npx tsc --noEmit`, `npm run lint -- --max-warnings=0`, `npm run build` (static export → `out/`).
- Preview production build: `npm run preview` (serves `out/` on :8000).
- E2E: `npm run test:e2e` (runs `next build` first). Playwright uses the installed Google Chrome via `channel: "chrome"`; do NOT run `npx playwright install` (downloads outside the project / npm registry).
- PWA: manifest is `public/manifest.json`, service worker `public/sw.js` (bump `VERSION` on strategy changes), registered only in production by `ServiceWorkerRegister`.
- `LayoutProps` global type is generated by `next build`/`next dev`; run a build before standalone `tsc`.
- Contact info / links live in `src/lib/site.ts`; marketing copy in `src/lib/content.ts`.
- lucide-react 1.x has no brand icons; brand SVGs live in `src/components/ui/BrandIcons.tsx`.
- Pin dependencies exactly and prefer versions published 7+ days ago.
- Story media: lesson cards in `public/media/yt/` come from official @ENGLISHBYMANISIR YouTube thumbnails via `npm run media:youtube`; video IDs and titles live in `REEL` in `src/lib/content.ts`.
- Pages: `/` (home), `/about`, `/gallery`, `/privacy`, `/terms`. Shared header/footer/modals live in `src/components/layout/SiteShell.tsx` (root layout). Nav links in `NAV_LINKS` use `/#section` for home sections. Per-page metadata via `pageMetadata()` in `src/lib/seo.ts`.
- Photos: originals in `assets/people/`, web versions via `npm run media:photos` into `public/media/people/`.
- Brand: official logo sources live in `assets/brand/`. Regenerate all logo/icon outputs (`public/brand/*`, `src/app/icon.png`, `src/app/apple-icon.png`) with `node scripts/build-brand-assets.mjs`.
- Theme colours come from the logo: `ember-*` (sunset orange), `sun-*` (gold), `bark-*` (eagle brown), warm `obsidian-*` backgrounds and `stone-*` neutrals, all defined in `src/app/globals.css`. Do not reintroduce emerald/cyan/slate.
- Bulk find/replace on class names must use word boundaries (a past `slate-`→`stone-` replace corrupted `translate-`).
- Speed rules: no Framer Motion (removed for bundle size); animations are CSS only (`.reveal` scroll-driven reveal, `animate-fade-up`, `animate-menu-in` in globals.css). Images must be pre-optimised WebP (no large PNGs at runtime; check with `.qa`-style perf runs or the `speed:` E2E tests).
- Privacy rules: the site sets no cookies and makes no third-party requests until the visitor acts (maps via click-to-load `MapEmbed`, YouTube only on play via youtube-nocookie, thumbnails served locally). E2E tests enforce this. Do not add analytics/trackers without adding a consent mechanism and updating `/privacy`.
- SEO: titles, description, keywords and share images live in `src/lib/seo.ts`; JSON-LD (LocalBusiness + FAQPage) in `src/components/JsonLd.tsx`; `src/app/sitemap.ts` and `robots.ts` emit static files. `SITE.url` defaults to `https://lifespokenenglish.pages.dev` (override with `NEXT_PUBLIC_SITE_URL` for a custom domain). FAQ text lives in `FAQS` in `src/lib/content.ts` and must stay visible in the home `#faq` section (Google requires FAQ schema to match on-page content). New pages must be added to the sitemap `ROUTES`.
- "Mani Sir" must never wrap across lines: in visible copy write `Mani\u00A0Sir` inside JS strings and `Mani&nbsp;Sir` in JSX text / JSX attribute literals (`SITE.founderAlias` already contains the NBSP). Keep plain spaces in metadata, JSON-LD (wrap with `plainText()`), WhatsApp messages, alt and aria-label text. Guarded by `tests/e2e/v10-name-nowrap.spec.ts`; in Playwright regexes use `Mani\s+Sir`.
- CMS: Contentful (`galleryItem`, `announcement`, `founderProfile`) is synced at build by `scripts/sync-cms.mts` (prebuild) into git-ignored `src/lib/cms.generated.json` + `public/media/cms/` (self-hosted WebP, so no third-party requests). Read it only via `src/lib/cms.ts` (falls back to `PHOTOS`, `ANNOUNCEMENT`, and `MANI_SIR` in content.ts). `src/lib/contentful.ts` must stay self-contained (npm imports only) because Node runs it directly; that is also why `.node-version` is 24 (native TypeScript). Editor text passes through `cleanText()` (dashes to " - ", NBSP in "Mani Sir"). Provisioning: `npm run cms:setup` (CMA, idempotent). Build-time sync automatically prunes orphaned/unpublished assets from `public/media/cms/`. E2E runs with `CMS_SYNC=off`. Secrets live only in `.env.local` (agents cannot read it); `.env.example` lists the names.
